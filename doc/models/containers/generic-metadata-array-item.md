
# Generic Metadata Array Item

An element of an array-valued metadata property: a string, number, boolean, or null. Nested objects and nested arrays are not allowed.

## Data Type

`str | None | int | float | bool`

## Cases

| Type |
|  --- |
| `str` |
| `int` |
| `float` |
| `bool` |

## str

### Initialization Code

#### Example

```python
value = 'sale'
```

## int

### Initialization Code

#### Example

```python
value = 10
```

## float

### Initialization Code

#### Example

```python
value = 10.5
```

## bool

### Initialization Code

#### Example

```python
value = True
```
